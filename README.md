Port Solano is a playable offline open-world crime game that runs in a desktop browser from static files: drive and walk a six-district coastal city, steal cars, outrun the police under a 0–5 star wanted system, fight through 8 story missions, and dodge traffic and pedestrians who flee when shots are fired. No network requests, no install — just the game.

## Run it

```sh
node serve.ts
```

Then open <http://localhost:8080> in a desktop browser. (`game/index.html` also opens directly; the server is only a convenience, the game itself fetches nothing.)
